## Overview

This is a website I built for **Gears Exteriors and Interlock**, a local landscaping and interlock company based in **Stittsville, Ontario**.

The company handles exterior work such as **patios, walkways, stone steps, and interlock installations** for homeowners in **Stittsville, Ottawa, Kanata, and surrounding areas**.

The site was built using plain **HTML, CSS, and JavaScript**. No frameworks, no build tools, and no unnecessary setup. The goal was to keep it clean, easy to edit, and focused on helping visitors call or request a quote.

## What’s Included

- Homepage with a hero section, company intro, services preview, reviews, and project gallery
- Separate pages for **About**, **Services**, **Gallery**, and **Contact**
- Contact form with basic validation for name, phone, email, project type, and message
- Filterable gallery with a click-to-enlarge lightbox
- Embedded Google Map showing the business location
- Mobile-friendly layout with a slide-down menu for smaller screens
- Earthy colour palette using dark greens, stone grey, and cream tones
